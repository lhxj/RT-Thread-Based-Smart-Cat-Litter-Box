# 硬件配置与引脚说明

本文用于说明当前仓库所对应的硬件组成、代码中已经接入的外设，以及实际引脚配置。

整理原则如下：

- 以仓库内现有代码和 BSP 配置为准
- 参考物料清单用于说明硬件构成，不等同于“当前代码全部已接入”
- 对于仓库中没有明确 GPIO / 总线绑定的器件，单独标注为“未在代码中形成明确约束”

## 1. 平台与板级基础

### 主控平台

- MCU：`HC32F460`
- RTOS：`RT-Thread`
- 控制台串口：`uart4`
- 联网模组：`ESP8266 AT Device`

### 板级总线与外设开关

当前 BSP / 软件包配置可从 [`rtconfig.h`](../rtconfig.h) 确认：

- `BSP_USING_UART2`
- `BSP_USING_UART4`
- `BSP_USING_I2C2`
- `PKG_USING_AT_DEVICE`
- `AT_DEVICE_USING_ESP8266`
- `PKG_USING_DHT11`
- `PKG_USING_SSD1306`
- `PKG_USING_BALANCE`

### 4.3 电源与公共约束

这一部分不属于仓库内的软件引脚配置，但接线时建议满足以下基础条件：

- 所有外设与主控共地
- 外设供电电压和 IO 电平以模块规格书为准
- ESP8266、OLED、HX711、DHT11 等模块上电后再进行软件联调
- 霍尔板、红外和电机驱动的信号地与主控地保持可靠连接

## 5. 硬件连接总览

下面的文本图用于建立整体接线认知，适合在接手项目时快速过一遍。

```text
                +----------------------+
                |      HC32F460        |
                |                      |
 红外占用  ----> | PE2                  |
 霍尔 POS1 ----> | PA4                  |
 霍尔 POS2 ----> | PA5                  |
 霍尔 POS3 ----> | PA6                  |
 DHT11 DATA --> | PE10                 |
 HX711 DOUT --> | PC0                  |
 HX711 SCK  --> | PC1                  |
 OLED SCL  <--> | PD0  (i2c2)          |
 OLED SDA  <--> | PD1  (i2c2)          |
 ESP8266 RX <-- | PA2  (uart2_tx)      |
 ESP8266 TX --> | PA3  (uart2_rx)      |
 Console TX --> | PE6  (uart4_tx)      |
 Console RX <-- | PB9  (uart4_rx)      |
 L298N IN1  <-- | PD8                  |
 L298N IN2  <-- | PD9                  |
 Buzzer CTRL <- | PD11                 |
 O3 CTRL     <- | PD10                 |
 LED         <- | PD4                  |
                +----------------------+
```

说明：

- 输入 / 输出方向均从 MCU 视角描述
- `uart2` 用于 ESP8266 联网
- `uart4` 用于日志、控制台和 finsh
- `i2c2` 为软件 I2C，总线引脚由 `rtconfig.h` 配置为 `PD0 / PD1`

## 7. 总线与串口配置

### 7.1 `uart4` 控制台

控制台相关配置来自 [`rtconfig.h`](../rtconfig.h) 和 [`board/board_config.h`](../board/board_config.h)：

| 项目 | 配置 |
| --- | --- |
| 设备名 | `uart4` |
| MCU TX | `PE6` |
| MCU RX | `PB9` |
| 默认串口参数 | `115200 8N1` |
| 用途 | RT-Thread 控制台、日志、finsh |

接线时通常遵循：

- 外部 USB 转串口 RX <- `PE6`
- 外部 USB 转串口 TX -> `PB9`

### 7.2 `uart2` ESP8266

ESP8266 相关配置来自 [`rtconfig.h`](../rtconfig.h) 与 [`board/board_config.h`](../board/board_config.h)：

| 项目 | 配置 |
| --- | --- |
| 设备名 | `uart2` |
| MCU TX | `PA2` |
| MCU RX | `PA3` |
| 用途 | ESP8266 AT Device |

接线时通常遵循：

- ESP8266 RX <- `PA2`
- ESP8266 TX -> `PA3`

说明：

- 仓库当前明确配置了 `uart2` 作为 ESP8266 AT client
- 仓库里没有看到 ESP8266 `EN` / `RST` / `IO0` 等额外控制脚的项目级绑定

### 7.3 `i2c2` OLED

OLED 使用软件 I2C，总线名为 `i2c2`。

| 项目 | 配置 |
| --- | --- |
| 总线名 | `i2c2` |
| SCL 配置值 | `48` |
| SDA 配置值 | `49` |
| 实际端口 | `PD0` / `PD1` |
| OLED 地址 | `0x3C` |

引脚换算依据：

- `GET_PIN(PORT, PIN) = port_index * 16 + pin`
- HC32 GPIO 端口编号：`A=0`、`B=1`、`C=2`、`D=3`、`E=4`
- 因此 `48 = 3*16 + 0 = PD0`，`49 = 3*16 + 1 = PD1`

## 8. HX711 / 称重通道说明

`balance` 软件包当前只启用了 `CH0`：

| 通道 | DOUT | SCLK | 状态 |
| --- | --- | --- | --- |
| `balance0` | `PC0` | `PC1` | 已启用 |
| `balance1` | 未配置 | 未配置 | 未启用 |
| `balance2` | 未配置 | 未配置 | 未启用 |

补充说明：

- 当前业务逻辑中的重量来源是 `cur_weight`
- 满仓阈值判断使用 `cur_weight >= 500`
- 仓库里虽然启用了 `ADC1`，但当前称重主线并不走 ADC，而是通过 HX711 bit-bang 驱动

## 9. 当前未形成明确引脚约束的器件

以下器件在参考物料清单中出现，但当前仓库没有形成单独、明确的引脚配置文档约束：

- 继电器
- 电池 / 电池盒 / 充电器
- 面包板、杜邦线
- 置物箱
- 磁铁本体

其中：

- 磁铁是 Hall 机械结构的一部分，软件只关心 Hall 输入结果
- 供电和结构件属于系统装配信息，不在当前仓库的软件引脚配置范围内

## 10. 接手开发时的建议

如果需要继续调试或扩展硬件，建议按下面顺序确认：

1. 先确认 `uart4` 控制台、`uart2` 联网、`i2c2` OLED 三条基础链路
2. 再确认 `PE2`、`PA4/PA5/PA6`、`PD8/PD9` 这些控制闭环关键引脚
3. 最后再补充未形成明确约束的辅助器件文档
